# Grok Bot Reference Examples

Use these examples as job shapes, not scripts. Choose the closest shape, then define its outcome, trigger, inputs, safe actions, approval boundary, evidence, and stopping condition.

Use the [Grok Bots directory](https://www.grokbots.page/) and [Bot Directory](https://botdirectory.ai/) as discovery sources. Confirm the required tools, permissions, schedule, and side effects before adapting a listing.

## Recurring operations

### Chief

Scans email and calendar on first install and each weekday morning, archives junk, drafts replies without sending, and returns a one-page brief of what matters and what the user must decide.

**Borrow:** Pair a stable cadence with a compact decision surface. Automate reversible cleanup and preparation; keep outbound communication under human control.

## Selection rule

Prefer one narrow job shape over a general assistant:

- **Deliver:** work until a visible check passes.
- **Investigate:** complete safe steps, then hand over the protected action.
- **Act:** execute within locked limits; escalate anything outside them.
- **Monitor:** run on a useful cadence and speak only when the output changes a decision.
- **Prepare:** gather, normalize, and draft; let the user commit.
- **Improve:** review evidence, propose one patch, and apply it after approval.
